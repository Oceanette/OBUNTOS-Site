    Dúvidas rápidas

    Antes de baixar.

    Preciso de internet para usar?

    Não para usar um perfil local. Internet só entra quando você usa recursos que dependem de conta ou sincronização.

    Onde ficam as minhas coisas?

    O perfil local fica no seu computador. Se você optar por sincronização, o conteúdo enviado é protegido antes de sair do aplicativo.

    Preciso criar uma conta?

    Não. Você pode começar e continuar usando o OBUNTOS com um perfil local. A conta é uma opção extra.

    O que posso guardar nele?

    Diário, tarefas, calendário, metas, pessoas, biblioteca com anexos, finanças e estatísticas fazem parte do arquivo.

    E o pendrive, para que serve?

    Ele pode ser usado como uma forma extra de acesso. Se você quiser, também pode configurar um modo que exige o pendrive para abrir o arquivo local.
